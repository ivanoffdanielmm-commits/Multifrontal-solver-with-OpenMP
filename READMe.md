# Математическое описание мультифронтального метода с $LDL^T$-разложением

## 1. Минимизация заполнения

Для сокращения заполнения применяется симметричная перестановка строк и столбцов, получаемая с помощью **эвристики минимальной степени**. Эвристика последовательно исключает вершины графа матрицы с наименьшей степенью, моделируя образование новых рёбер.

* **Вход:** симметричная матрица $A$ размера $n \times n$ (задан нижний треугольник).
* **Выход:** вектор перестановки $\pi[0..n-1]$ и обратная перестановка $\pi^{-1}$, где $\pi^{-1}[\pi[i]] = i$.

### Формальные шаги
1. Для каждого узла $i$ построить множество соседей:
   $$\mathrm{adj}(i) = \{j \neq i \mid a_{ij} \neq 0\}$$
2. Все вершины считаются активными: $\mathrm{active}[i] = \mathrm{true}$.
3. Для $k = 0, 1, \ldots, n-1$:
   * Выбрать активную вершину $v$ с минимальной мощностью $|\mathrm{adj}(v)|$.
   * Зафиксировать её в перестановке: $\pi[k] = v$, $\mathrm{active}[v] = \mathrm{false}$.
   * Для каждой пары активных соседей $u, w \in \mathrm{adj}(v), u \neq w$, если ребро $(u,w)$ ещё не существует, добавить его:
     $$\mathrm{adj}(u) \gets \mathrm{adj}(u) \cup \{w\}, \quad \mathrm{adj}(w) \gets \mathrm{adj}(w) \cup \{u\}$$
   * Удалить $v$ из списков смежности всех соседей: для каждого $u \in \mathrm{adj}(v)$ выполнить:
     $$\mathrm{adj}(u) \gets \mathrm{adj}(u) \setminus \{v\}$$

> Дальнейшая работа ведётся с переставленной матрицей $A = P A P^T$, где $P$ — матрица перестановки, соответствующая вектору $\pi$.

## 2. Построение дерева исключения

Дерево исключения определяет зависимости между столбцами в ходе факторизации. Родителем столбца $j$ становится наименьший индекс $i > j$, такой что столбец $j$ непосредственно обновляет столбец $i$.

Дерево используется для:
* Установления порядка обхода узлов при сборке фронтальных матриц.
* Выявления полностью собранных переменных.

Построение выполняется с применением **сжатия путей**, что обеспечивает практически линейную сложность относительно числа ненулевых элементов.

* **Вход:** переставленная матрица $A$ (используются только элементы $a_{ij}$ с $i > j$).
* **Выход:** массив $\mathrm{parent}[0..n-1]$, где $\mathrm{parent}[j]$ — родитель вершины $j$ ($\mathrm{parent}[j] = -1$ для корней).

### Формальные шаги
1. **Инициализация:**
   $$\mathrm{parent}[i] = -1, \quad \mathrm{ancestor}[i] = -1 \quad (0 \le i < n)$$
2. **Основной цикл:**
   Для $i = 0, 1, \ldots, n-1$:
   &emsp;Для каждого $j < i$, такого что $a_{ij} \neq 0$:
   &emsp;&emsp;$r \gets j$
   &emsp;&emsp;Пока $\mathrm{ancestor}[r] \neq -1$ и $\mathrm{ancestor}[r] \neq i$:
   &emsp;&emsp;&emsp;$t \gets \mathrm{ancestor}[r]$, $\mathrm{ancestor}[r] \gets i$, $r \gets t$
   &emsp;&emsp;Если $\mathrm{ancestor}[r] = -1$:
   &emsp;&emsp;&emsp;$\mathrm{ancestor}[r] \gets i$, $\mathrm{parent}[r] \gets i$

> Операция $\mathrm{ancestor}[r] \gets i$ реализует сжатие пути.

После построения дерева для каждого узла $k$ определяется множество полностью собранных переменных $\mathcal{F}_k$ как множество индексов, для которых узел $k$ является наименьшим общим предком всех вхождений переменной в структуру $A$. Вычисление опирается на списки $\mathrm{nodeVars}[k] = \{k\} \cup \{i > k \mid a_{ik} \neq 0\}$ и последующий подъём к наименьшему общему предку.

## 3. Мультифронтальная факторизация

Численная факторизация выполняется путем обхода дерева исключения в **пост-порядке** (снизу вверх).

Для каждого узла $k$:
1. Собирается плотная фронтальная матрица.
2. В неё добавляются элементы исходной матрицы $A$ и блоки вклада от дочерних узлов.
3. Производится частичное $LDL^T$-разложение с выбором ведущего элемента размера $1 \times 1$ или $2 \times 2$ (использование блоков $2 \times 2$ обеспечивает устойчивость для симметричных неопределённых матриц).

### 3.1 Сборка фронтальной матрицы

* **Вход:** узел $k$, списки $\mathrm{nodeVars}[k]$, блоки вклада $C_c$ от детей $c \in \mathrm{children}(k)$, матрица $A$.
* **Выход:** глобальное индексное множество $I_k$ размера $m$ и плотная матрица $F_k \in \mathbb{R}^{m \times m}$ (исходно нулевая).

#### Формальные шаги
1. **Формирование $I_k$:**
   $$I_k = \mathrm{nodeVars}[k] \cup \left( \bigcup_{c \in \mathrm{children}(k)} \{\text{глобальные индексы из } C_c\} \right)$$
   Множество $I_k$ упорядочивается по возрастанию; $m = |I_k|$.
2. **Добавление элементов $A$:**
   Для каждого ненулевого $a_{uv}\ (u \ge v)$:
   * если $u \in I_k$ и $v \in I_k$, определить локальные индексы $i = \mathrm{pos}(u)$, $j = \mathrm{pos}(v)$;
   * выполнить $F_k[i][j] \mathrel{+}= a_{uv}$; если $i \neq j$: $F_k[j][i] \mathrel{+}= a_{uv}$.
3. **Добавление вкладов детей (операция расширения-сложения):**
   Для каждого ребёнка $c$ с блоком $C_c$:
   &emsp;Для каждого элемента $C_c(r,s)$ с глобальными индексами строки $g_r$ и столбца $g_s$:
   &emsp;&emsp;$i = \mathrm{pos}(g_r)$, $j = \mathrm{pos}(g_s)$;
   &emsp;&emsp;$F_k[i][j] \mathrel{+}= C_c(r,s)$.

### 3.2 Частичное $LDL^T$-разложение фронта

Пусть $\mathcal{S} \subset \{0, \ldots, m-1\}$ — множество локальных индексов, соответствующих полностью собранным переменным $\mathcal{F}_k \cap I_k$. Число таких переменных $p = |\mathcal{S}|$. Остальные индексы являются не полностью собранными.

* **Вход:** $F_k$, $p$, порог устойчивости $\tau$.
* **Выход:** нижняя треугольная матрица $L_k$ (с единичной диагональю), блочно-диагональная $D_k$ (набор $1 \times 1$ и $2 \times 2$ блоков), обновлённая матрица $F_k$.

#### Формальные шаги
1. **Построение перестановки $\sigma$:** сначала индексы из $\mathcal{S}$ по возрастанию, затем остальные.
2. **Симметричная перестановка $F_k$:**
   $$F_k[i][j] = F_k[\sigma[i]][\sigma[j]], \quad 0 \le i, j < m$$
   Инициализация $L_k$ нулевой матрицей размера $m \times m$.
3. **Пошаговое исключение** ($\mathrm{step} = 0$):
   Пока $\mathrm{step} < p$:

   **а) Поиск ведущего элемента $1 \times 1$:**
   Для каждого $t$ от $\mathrm{step}$ до $p-1$ положить $\mathrm{piv} = F_k[t][t]$.
   *Условие приёма:*
   $$|\mathrm{piv}| > \tau \quad \text{и} \quad |\mathrm{piv}| \ge 0.1 \cdot \max_{r \ge \mathrm{step},\ r \neq t} |F_k[r][t]|$$
   Среди подходящих выбирается $t^*$ с наибольшим $|\mathrm{piv}|$.
   Если $t^*$ существует:
   * Переставить строки и столбцы $\mathrm{step}$ и $t^*$ в $F_k$ и $L_k$;
   * $d \gets F_k[\mathrm{step}][\mathrm{step}]$; сохранить $d$ как блок $1 \times 1$ в $D_k$;
   * Для $i = \mathrm{step}+1, \ldots, m-1$: $\ell_i = F_k[i][\mathrm{step}] / d$, $L_k[i][\mathrm{step}] = \ell_i$;
   * **Обновление Шура:** $F_k[i][j] \gets F_k[i][j] - \ell_i \cdot d \cdot \ell_j \quad (i,j = \mathrm{step}+1, \ldots, m-1)$;
   * $\mathrm{step} \gets \mathrm{step} + 1$.

   **б) Поиск ведущего элемента $2 \times 2$ (если $1 \times 1$ не найден):**
   Осуществляется поиск пары $u,v \ (\mathrm{step} \le u < v < p)$ такой, что:
   $$a = F_k[u][u], \quad b = F_k[u][v], \quad c = F_k[v][v], \quad \mathrm{det} = ac - b^2, \quad |\mathrm{det}| > 10^{-12}$$
   При обнаружении:
   * Переставить $u \to \mathrm{step}$, $v \to \mathrm{step}+1$ в $F_k$ и $L_k$;
   * Пересчитать $a,b,c$ в новых позициях $\mathrm{step}, \mathrm{step}+1$;
   * Сформировать блок $D_{\mathrm{step}} = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$ и обратную матрицу $D_{\mathrm{step}}^{-1} = \frac{1}{\mathrm{det}} \begin{pmatrix} c & -b \\ -b & a \end{pmatrix}$;
   * Для $r = \mathrm{step}+2, \ldots, m-1$ вычислить:
     $$(\ell_{r,\mathrm{step}},\ \ell_{r,\mathrm{step}+1}) = (F_k[r][\mathrm{step}], F_k[r][\mathrm{step}+1]) \cdot D_{\mathrm{step}}^{-1}$$
     $$L_k[r][\mathrm{step}] = \ell_{r,\mathrm{step}}, \quad L_k[r][\mathrm{step}+1] = \ell_{r,\mathrm{step}+1}$$
   * **Обновление Шура:** для $r,c = \mathrm{step}+2, \ldots, m-1$:
     $$F_k[r][c] \gets F_k[r][c] - (\ell_{r,\mathrm{step}}, \ell_{r,\mathrm{step}+1}) \cdot D_{\mathrm{step}} \cdot (\ell_{c,\mathrm{step}}, \ell_{c,\mathrm{step}+1})^T$$
   * $\mathrm{step} \gets \mathrm{step} + 2$.

   **в) Если ведущие элементы не найдены:**
   Матрица считается численно вырожденной, факторизация прекращается.

### 3.3 Формирование блока вклада для родителя

Часть матрицы $F_k$, соответствующая не полностью собранным переменным (позиции $p, \ldots, m-1$), образует блок вклада $C_k$, передаваемый родительскому узлу.

Формально, при $m > p$:
$$C_k(i,j) = F_k[p+i][p+j], \quad i,j = 0, \ldots, m-p-1$$
Если $m = p$, блок вклада не создаётся.

## 4. Решение системы (прямой и обратный ход)

После факторизации решение исходной системы $Ax = b$ сводится к последовательному решению двух треугольных систем:
1. $Ly = b$
2. $DL^Tx = y$

Матрицы $L$ и $D$ распределены по структурам фронтальных матриц.

### 4.1 Прямой ход ($Ly = b$)

Выполняется обход дерева исключения в **пост-порядке** (снизу вверх). Для каждого фронта $k$ с глобальными индексами $I_k$, перестановкой $\sigma_k$ и матрицей $L_k$:

1. Извлекается локальный вектор $y_{\mathrm{loc}}$ в порядке $\sigma_k$:
   $$y_{\mathrm{loc}}[i] = y[I_k[\sigma_k[i]]], \quad i = 0, \ldots, m-1$$
2. Решается нижняя треугольная система с единичной диагональю:
   Для $i = 0, \ldots, m-1$:
   $$y_{\mathrm{loc}}[i] \gets y_{\mathrm{loc}}[i] - \sum_{j=0}^{i-1} L_k[i][j] \cdot y_{\mathrm{loc}}[j]$$
3. Обновлённые значения записываются обратно в глобальный вектор:
   $$y[I_k[\sigma_k[i]]] = y_{\mathrm{loc}}[i]$$

### 4.2 Обратный ход ($DL^Tx = y$)

Выполняется обход дерева в порядке, **обратном пост-обходу** (сверху вниз). Для каждого фронта $k$:

1. Извлекается локальный вектор $z_{\mathrm{loc}}$:
   $$z_{\mathrm{loc}}[i] = y[I_k[\sigma_k[i]]], \quad i = 0, \ldots, m-1$$
2. Решается система $Dw = z_{\mathrm{loc}}$ (масштабирование с учётом блоков $2 \times 2$).
   Полагается $s = 0$. Пока $s < p$:
   * Если блок $1 \times 1$ с элементом $d_s$:
     $$w[s] = z_{\mathrm{loc}}[s] / d_s, \quad s \gets s+1$$
   * Если блок $2 \times 2$ вида $D_2 = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$ на позициях $s, s+1$:$$\begin{pmatrix} w[s] \ w[s+1] \end{pmatrix} = D_2^{-1} \begin{pmatrix} z_{\mathrm{loc}}[s] \ z_{\mathrm{loc}}[s+1] \end{pmatrix}, \quad s \gets s+2$$
• Для $s \ge p$ принимается:
$$w[s] = z_{\mathrm{loc}}[s]$$
3. Выполняется обратная подстановка $L_k^T x_{\mathrm{loc}} = w$:
Для $j = m-1, \ldots, 0$:
$$x_{\mathrm{loc}}[j] = w[j] - \sum_{i=j+1}^{m-1} L_k[i][j] \cdot x_{\mathrm{loc}}[i]$$
4. Результат записывается в глобальный вектор:
$$x[I_k[\sigma_k[i]]] = x_{\mathrm{loc}}[i], \quad i = 0, \ldots, m-1$$
После обработки всех фронтов вектор $x$ содержит решение исходной системы линейных уравнений $Ax = b$.
