# Математическое описание мультифронтального метода с $LDL^T$-разложением

В данном документе приведено строгое математическое описание и формальные шаги алгоритмов, составляющих мультифронтальный метод решения разреженных симметричных систем линейных уравнений с применением устойчивого $LDL^T$-разложения (с возможностью выбора ведущих элементов размера $1\times1$ и $2\times2$).

---

## 1. Минимизация заполнения

Для сокращения появления новых ненулевых элементов (заполнения) в процессе факторизации применяется симметричная перестановка строк и столбцов, получаемая с помощью **эвристики минимальной степени (Minimum Degree Ordering)**. Эвристика последовательно исключает вершины графа матрицы с наименьшей степенью, моделируя образование новых рёбер (кликов).

* **Вход:** Симметричная матрица $A$ размера $n \times n$ (задан нижний треугольник).
* **Выход:** Вектор перестановки $\pi[0..n-1]$ и обратная перестановка $\pi^{-1}$, где $\pi^{-1}[\pi[i]] = i$.

### Формальные шаги:
1. Для каждого узла $i$ построить множество соседей:
   $$\mathrm{adj}(i) = \{j \neq i \mid a_{ij} \neq 0\}$$
2. Все вершины считаются активными: $\mathrm{active}[i] = \mathrm{true}$.
3. Для $k = 0, 1, \ldots, n-1$:
   * Выбрать активную вершину $v$ с минимальной мощностью $|\mathrm{adj}(v)|$.
   * Зафиксировать её в перестановке: $\pi[k] = v$, $\mathrm{active}[v] = \mathrm{false}$.
   * **Обновление графа (исключение вершины):** Для каждой пары активных соседей $u, w \in \mathrm{adj}(v)$, $u \neq w$, если ребро $(u,w)$ ещё не существует, добавить его:
     $$\mathrm{adj}(u) \gets \mathrm{adj}(u) \cup \{w\}, \quad \mathrm{adj}(w) \gets \mathrm{adj}(w) \cup \{u\}$$
   * Удалить $v$ из списков смежности всех соседей: для $u \in \mathrm{adj}(v)$ выполнить:
     $$\mathrm{adj}(u) \gets \mathrm{adj}(u) \setminus \{v\}$$

> [!NOTE]
> Дальнейшая работа ведётся с переставленной матрицей $A = P A P^T$, где $P$ — матрица перестановки, соответствующая вектору $\pi$.

---

## 2. Построение дерева исключения

**Дерево исключения** определяет зависимости между столбцами в ходе факторизации. Родителем столбца $j$ становится наименьший индекс $i > j$, такой что столбец $j$ непосредственно обновляет столбец $i$. 

Дерево используется для:
* Установления порядка обхода узлов при сборке фронтальных матриц.
* Выявления полностью собранных переменных.

Построение выполняется с применением **сжатия путей**, что обеспечивает практически линейную сложность алгоритма относительно числа ненулевых элементов.

* **Вход:** Переставленная матрица $A$ (используются только элементы $a_{ij}$ с $i > j$).
* **Выход:** Массив $\mathrm{parent}[0..n-1]$, где $\mathrm{parent}[j]$ — родитель вершины $j$ ($\mathrm{parent}[j] = -1$ для корней дерева).

### Формальные шаги:
1. **Инициализация:** 
   $$\mathrm{parent}[i] = -1, \quad \mathrm{ancestor}[i] = -1 \quad (0 \le i < n)$$
2. **Основной цикл:**
   ```pascal
   для i = 0, 1, ..., n-1:
       для каждого j < i, такого что a_ij ≠ 0:
           r = j
           пока ancestor[r] ≠ -1 и ancestor[r] ≠ i:
               t = ancestor[r]
               ancestor[r] = i  // Сжатие пути
               r = t
           если ancestor[r] == -1:
               ancestor[r] = i
               parent[r] = i
   ```

После построения дерева для каждого узла $k$ определяется множество полностью собранных переменных $\mathcal{F}_k$ как множество индексов, для которых узел $k$ является наименьшим общим предком всех вхождений переменной в структуру $A$. 

Вычисление опирается на списки:
$$\mathrm{nodeVars}[k] = \{ k \} \cup \{ i > k \mid a_{ik} \neq 0 \}$$
и последующий подъём к наименьшему общему предку.

## 3. Мультифронтальная факторизация

Численная факторизация выполняется путем обхода дерева исключения в **пост-порядке (post-order, снизу вверх)**. Для каждого узла $k$:
1. Собирается плотная **фронтальная матрица** $F_k$.
2. В неё добавляются элементы исходной матрицы $A$ и блоки вклада (update matrices) от дочерних узлов.
3. Производится частичное $LDL^T$-разложение с выбором ведущего элемента размера $1\times1$ или $2\times2$ (для обеспечения устойчивости неопределённых матриц).

### 3.1. Сборка фронтальной матрицы

* **Вход:** Узел $k$, списки списки $\mathrm{nodeVars}[\mathrm{k}]$, блоков вклада $C_c$ от детей $c \in \mathrm{children}(k)$, матрица $A$.
* **Выход:** Глобальное индексное множество $I_k$ размера $m$ и плотная фронтальная матрица $F_k \in \mathbb{R}^{m \times m}$ (исходно нулевая).

#### Формальные шаги:
1. **Формирование $I_k$:**
   $$I_k = \mathrm{nodeVars}[k] \cup \left( \bigcup_{c \in \mathrm{children}(k)} \{\text{глобальные индексы из } C_c\} \right)$$
   Множество $I_k$ упорядочивается по возрастанию; $m = |I_k|$.
2. **Добавление элементов матрицы $A$:**
   Для каждого ненулевого $a_{uv}$ ($u \ge v$):
   * Если $u \in I_k$ и $v \in I_k$, определить локальные индексы: $i = \mathrm{pos}(u)$, $j = \mathrm{pos}(v)$.
   * Выполнить: $F_k[i][j] \mathrel{+}= a_{uv}$. Если $i \neq j$, то $F_k[j][i] \mathrel{+}= a_{uv}$.
3. **Операция расширения-сложения (Extend-Add) для вкладов детей:**
   Для каждого дочернего узла $c$ с блоком вклада $C_c$:
   * Для каждого элемента $C_c(r,s)$ с глобальными индексами строки $g_r$ и столбца $g_s$:
     $$i = \mathrm{pos}(g_r), \quad j = \mathrm{pos}(g_s)$$
     $$F_k[i][j] \mathrel{+}= C_c(r,s)$$

---

### 3.2. Частичное $LDL^T$-разложение фронта

Пусть $\mathcal{S} \subset \{0, \ldots, m-1\}$ — множество локальных индексов, соответствующих полностью собранным переменным $\mathcal{F}_k \cap I_k$. Число таких переменных $p = |\mathcal{S}|$. Остальные индексы соответствуют не полностью собранным переменным.

* **Вход:** Фронтальная матрица $F_k$, число переменных $p$, порог устойчивости $\tau$.
* **Выход:** Нижняя треугольная матрица $L_k$ (с единичной диагональю), блочно-диагональная матрица $D_k$ (набор блоков $1\times1$ и $2\times2$), обновлённая матрица фронта $F_k$.

#### Формальные шаги:
1. **Симметричная перестановка фронта:**
   Построить перестановку $\sigma$: сначала индексы из $\mathcal{S}$ по возрастанию, затем остальные. Переставить $F_k$:
   $$F_k[i][j] = F_k[\sigma[i]][\sigma[j]], \quad 0 \le i, j < m$$
   Инициализировать $L_k$ нулевой матрицей размера $m \times m$.
2. **Пошаговое исключение (переменная $\mathrm{step} = 0$):**
   Пока $\mathrm{step} < p$:

   * **а) Поиск $1\times1$ ведущего элемента:**
     Для каждого $t$ от $\mathrm{step}$ до $p-1$ положить $\mathrm{piv} = F_k[t][t]$.
     Условие приёма элемента:
     $$|\mathrm{piv}| > \tau \quad \text{и} \quad |\mathrm{piv}| \ge 0.1 \cdot \max_{r \ge \mathrm{step},\, r \neq t} |F_k[r][t]|$$
     Среди подходящих выбирается $\mathrm{t}^{\ast}$ с наибольшим $|\mathrm{piv}|$. Если $\mathrm{t}^{\ast}$ найден:


     1. Переставить строки и столбцы $\mathrm{step}$ и $t^*$ в $F_k$ и $L_k$.
     2. $d \gets F_k[\mathrm{step}][\mathrm{step}]$; сохранить $d$ как блок $1\times1$ в $D_k$.
     3. Для $i = \mathrm{step}+1, \ldots, m-1$: выписать множители $\ell_i = F_k[i][\mathrm{step}] / d$, положить $L_k[i][\mathrm{step}] = \ell_i$.
     4. **Обновление Шура:** $F_k[i][j] \gets F_k[i][j] - \ell_i \cdot d \cdot \ell_j$ для $i, j = \mathrm{step}+1, \ldots, m-1$.
     5. $\mathrm{step} \gets \mathrm{step} + 1$.

   * **б) Поиск $2\times2$ ведущего элемента (если $1\times1$ не найден):**
     Ищется пара индексов $u, v$ ($\mathrm{step} \le u < v < p$), удовлетворяющая условиям стабильности, где:
     $$a = F_k[u][u], \quad b = F_k[u][v], \quad c = F_k[v][v], \quad \mathrm{det} = ac - b^2, \quad |\mathrm{det}| > 10^{-12}$$
     При обнаружении стабильной пары:
     1. Переставить $u \rightarrow \mathrm{step}$, $v \rightarrow \mathrm{step}+1$ в $F_k$ и $L_k$.
     2. Пересчитать значения $a, b, c$ в новых позициях.
     3. 3. Сформировать блок и его обратную матрицу:
     <br>
     <img src="https://githubusercontent.com_{\text{step}}%20=%20\begin{pmatrix}%20a%20&%20b%20\\%20b%20&%20c%20\end{pmatrix},%20\quad%20D_{\text{step}}^{-1}%20=%20\frac{1}{\text{det}}%20\begin{pmatrix}%20c%20&%20-b%20\\%20-b%20&%20a%20\end{pmatrix}">
     4. Для $r = \text{step}+2, \ldots, m-1$ вычислить строку множителей: 
     $$(\ell_{r,\,\text{step}}, \, \ell_{r,\,\text{step}+1}) = \begin{pmatrix} F_k[r][\text{step}] & F_k[r][\text{step}+1] \end{pmatrix} D_{\text{step}}^{-1}$$
     Записать их в $L_k[r][\text{step}]$ и $L_k[r][\text{step}+1]$.
     5. **Обновление Шура:** Для $r, c = \text{step}+2, \ldots, m-1$: 
     $$F_k[r][c] \gets F_k[r][c] - \begin{pmatrix} \ell_{r,\,\text{step}} & \ell_{r,\,\text{step}+1} \end{pmatrix} D_{\text{step}} \begin{pmatrix} \ell_{c,\,\text{step}} \\ \ell_{c,\,\text{step}+1} \end{pmatrix}^{T}$$
     6. Увеличить шаг алгоритма на 2: $s \gets s + 2$.





> [!CAUTION]
> Если на текущем шаге не удаётся найти ни $1\times1$, ни $2\times2$ ведущие элементы, матрица считается численно вырожденной, и процесс факторизации аварийно прекращается.

---

### 3.3. Формирование блока вклада для родителя

Часть обновлённой матрицы $F_k$, соответствующая не полностью собранным переменным (позиции от $p$ до $m-1$), образует матрицу вклада $C_k$, передаваемую на уровень выше.

При $m > p$:
$$C_k(i,j) = F_k[p+i][p+j], \quad i, j = 0, \ldots, m-p-1$$
Если $m = p$, блок вклада для данного узла не создаётся.

## 4. Решение системы (Прямой и Обратный ход)

После успешной факторизации решение исходной системы $Ax = b$ сводится к последовательному нахождению векторов из двух треугольных систем: $Ly = b$ и $DL^Tx = y$. Матрицы $L$ и $D$ хранятся распределённо в структурах фронтальных матриц.

### 4.1 Прямой ход ($Ly = b$)

Выполняется обход дерева исключения в **пост-порядке** (снизу вверх). Для каждого фронта $k$ с глобальными индексами $I_k$, перестановкой $\sigma_k$ и матрицей $L_k$:

1. Извлекается локальный вектор $y_{\mathrm{loc}}$ в порядке $\sigma_k$:
   $$y_{\mathrm{loc}}[i] = y[I_k[\sigma_k[i]]], \quad i = 0, \ldots, m-1$$
2. Решается нижняя треугольная система с единичной диагональю:
   Для $i = 0, \ldots, m-1$:
   $$y_{\mathrm{loc}}[i] \gets y_{\mathrm{loc}}[i] - \sum_{j=0}^{i-1} L_k[i][j] \cdot y_{\mathrm{loc}}[j]$$
3. Обновлённые значения записываются обратно в глобальный вектор:
   $$y[I_k[\sigma_k[i]]] = y_{\mathrm{loc}}[i]$$


4.2. Обратный ход ($DL^Tx = y$)

Выполняется обход дерева в порядке, обратном пост-обходу (сверху вниз). Для каждого фронтального узла $k$:
1. Извлечь локальный вектор:
$$z_{\mathrm{loc}}[i] = y[I_k[\sigma_k[i]]], \quad i = 0, \ldots, m-1$$
2. Решить блочно-диагональную систему $Dw = z_{\mathrm{loc}}$ с учетом размеров блоков.
Положить $s = 0$. Пока $s < p$:
	• Если на позиции $s$ находится блок $1\times1$ с элементом $d_s$:
$$w[s] = \frac{z_{\mathrm{loc}}[s]}{d_s}, \quad s \gets s+1$$
	• Если на позициях $s, s+1$ находится блок $2\times2$ матрицы $D_2 = \begin{pmatrix} a & b \ b & c \end{pmatrix}$:
$$\begin{pmatrix} w[s] \ w[s+1] \end{pmatrix} = D_2^{-1} \begin{pmatrix} z_{\mathrm{loc}}[s] \ z_{\mathrm{loc}}[s+1] \end{pmatrix}, \quad s \gets s+2$$
	• Для не полностью собранных переменных ($s \ge p$) оставить значения без изменений:
$$w[s] = z_{\mathrm{loc}}[s]$$
3. Выполнить обратную подстановку $L_k^T x_{\mathrm{loc}} = w$:
Для $j = m-1, m-2, \ldots, 0$:
$$x_{\mathrm{loc}}[j] = w[j] - \sum_{i=j+1}^{m-1} L_k[i][j] \cdot x_{\mathrm{loc}}[i]$$
4. Записать вычисленный результат в глобальный вектор решения:
$$x[I_k[\sigma_k[i]]] = x_{\mathrm{loc}}[i], \quad i = 0, \ldots, m-1$$
После обхода всех узлов дерева вектор $x$ содержит искомое решение системы линейных уравнений.
